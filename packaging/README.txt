Location Switch 0.1.0

Extract the entire ZIP before starting. Python and dependencies are bundled.
Mac: double-click start.command. Windows: double-click LocationSwitch.exe.
The control panel opens at http://127.0.0.1:8765. Keep the console open.
Connect/unlock your iPhone and Trust this computer. Enable Developer Mode
using the panel and confirm the required steps on your phone. First spoof
can download a developer image; internet is needed for that setup.

Windows requires Apple's USB device drivers (install Apple Devices from
Microsoft Store first). iOS 17.0-17.3.1 also needs a privileged tunneld;
see README.md. Current iOS 17.4+ uses the upstream no-admin tunnel.

These builds are unsigned. macOS may require Open via its normal security
approval; Windows may show SmartScreen. No signing identity is bundled.
The Windows device workflow has not been tested with physical hardware.

Restore real location in the panel before disconnecting or closing.
For help and source: https://github.com/Dankcode/location-switch
